Esquema kl · PostgreSQL existente

Modelo de datos

Contenido de versión inmutable por trigger; el estado solo cambia por transición permitida y cada cambio deja una fila en kl.audit_event. Referencia canónica de toda pieza: unit_key@versión. Un periodo nuevo es una unidad nueva; una corrección, una versión nueva.
